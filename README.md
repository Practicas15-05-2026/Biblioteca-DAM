# Biblioteca-DAM
Aplicación web para gestionar libros y usuarios

# Requisitos
npm 
Node.js

# Puesta en marcha del proyecto
1. Clonar repositorio -- git clone
2. Instalar las dependencias npm install
3. Inicializar el repositorio npm start
4. Aplicación web en http://localhost:3000

# Idiomas
Selección de idiomas en los botones de la esquina superior (ES o GB)

# Funcionalidades
1. Crud completo de usuarios y libros con manejo de errores 201, 400 y 404
2. Operaciones para trabajar con imagenes
3. Todos los textos están traducidos en español e inglés
4. Bootstrap para la visualización del listado de los libros
5. Relaciones entre las tablas usuarios y libros
6. Fetch para ejecutar de forma asincrona el CRUD de usuarios y libros
7. Diseño responsive
